# Personal Portfolio Website

A simple and responsive personal portfolio website created to showcase my background, skills, projects, documents, and experience as a **BS Information Technology student**.

## About the Project

This portfolio was created as a personal website where I can present my IT skills, academic projects, networking activities, web development projects, and other accomplishments.

I am a **Third-Year BSIT student at the Polytechnic University of the Philippines – Calauan Campus**, aspiring to become a **Network Administrator** while also developing my skills in web development and UI design.

## Purpose

The main purpose of this portfolio is to:

- Introduce myself as an IT student
- Showcase my academic and programming projects
- Demonstrate my networking skills and activities
- Present my web development experience
- Provide access to my resume and GitHub repositories
- Serve as an online portfolio for future internship opportunities

## Features

- **About Me** – Personal introduction, education, and technical skills
- **Projects** – Collection of networking, programming, and web development projects
- **Documents** – Online resume viewing and downloading
- **GitHub Repositories** – Displays my GitHub projects
- **Contact Section** – Provides ways to get in touch
- **Responsive Design** – Designed to work on desktop and mobile devices
- **Dark Mode Support** – Automatically adapts to the user's system appearance
